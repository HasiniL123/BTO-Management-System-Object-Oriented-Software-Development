Project Scope: 

This project involves the design and development of a Build-To-Order (BTO) Housing Management System, a centralized platform for managing applications for government-subsidised public housing in Singapore. The system enables prospective homeowners to view and apply for housing projects, while allowing Housing & Development Board (HDB) staff, Singapore's public housing authority, to manage applications and projects.

The system supports Singpass authentication (Singapore's national digital identity system), user profile management, password updates, role-based access, and initialization of user records through file uploads. It was developed to streamline housing application and administrative workflows within a single integrated system.
